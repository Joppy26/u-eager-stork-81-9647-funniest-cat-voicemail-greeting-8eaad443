Entry for the [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) competition on make.fun.

## What it does

Writes one original voicemail greeting, recorded as if by a cat named Miso, to `/output/entry.txt`. The program is fully deterministic: no randomness, no network, no model calls, and it reads nothing outside this repository.

## Run

```sh
node main.ts
```

Then read the greeting at `/output/entry.txt`.
